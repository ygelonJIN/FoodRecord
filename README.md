# 饮食记录 FoodRecord

一个单文件的本地饮食记录工具。苹果原生风格，纯文字界面，手机上打开即用，不联网、不发布 App。

## 怎么用

**电脑上**：双击 `启动.command`，会自动打开浏览器。

**手机上**（和电脑连同一个 WiFi）：

1. 双击 `启动.command`，终端会显示 `手机访问: http://192.168.x.x:8777`
2. 手机**用 Safari** 打开这个地址（不要用微信、QQ、备忘录里的内置浏览器打开，那些没有「添加到主屏幕」）
3. Safari 底部「分享」→ 往下翻 →「添加到主屏幕」→ 名字写「饮食」→ 添加
4. 之后从桌面图标打开。这个图标依赖电脑开着服务：电脑睡眠、换 WiFi、没双击 `启动.command`，点开就是白屏

地址里那个 IP 会随路由器重新分配而变。更稳的写法是把电脑主机名用上：`http://jinfeiqingdeMacBook-Pro.local:8777`（同一 WiFi 下等效，IP 变了也不受影响）。

**加不到桌面怎么办**：多半是打开方式不对。下到「文件」里的 `index.html` 只能在「文件」里预览，那种页面没有「添加到主屏幕」，也没法稳定存数据——要的是「Safari 打开一个网址」，不是「打开一个文件」。

**想让图标长期可用（不依赖电脑）**：这个仓库可以开 GitHub Pages，得到 `https://ygelonJIN.github.io/FoodRecord/` 这种 https 地址，手机在任何网络下都能打开，加到桌面后图标永远有效（数据仍然只存在这台手机里）。仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save，等一两分钟即可。

**只想在一台机器上用**：直接双击 `index.html` 也行，但用 Safari 打开本地文件时浏览器可能不给存数据，建议用上面的服务方式。

**手机和电脑的数据不互通**：每台设备、每个地址（`http://IP:8777` 和 `https://...github.io` 算两个）各存各的。「设置」页导出 JSON → 另一台导入，是唯一搬数据的办法。

## 功能

- 按天记录，四个餐次：早餐 / 午餐 / 晚餐 / 加餐，加餐可以记多条
- 每餐左侧一个加号，点它加食物；同一行右侧是这餐的碳水、蛋白质、脂肪、糖、热量，用黑色
- 每条食物一行，份数写在名字最前面（`2× 鸡蛋`），数字用黑色
- 条目右侧是这条的碳水、蛋白质、脂肪、糖、热量，用灰色（和餐头区分层级）
- 四项营养一律写全称，不缩写；单位 g 和 kcal 都写出来，不省略
- 顶部是「总量」卡，五行横排：碳水、蛋白质、脂肪、糖、热量，一行一项，各带进度条和「当前 / 目标」
- 进度条统一蓝色，超标的数字变红，条不变色
- 任何改动（加、删、改份数、换目标）立刻重算
- 超标自动标红，并在顶部点名哪项超了多少
- 统计页：近 7 天 / 近 30 天 / 近 365 天的日均摄入，每段都标了起止日期
- 历史：所有有记录的日子排成列表，点一下就回到那天
- 食物库预置了 8 种常吃的，可以随时新建、编辑、删除
- 目标按体重推算：碳水 3 g/kg、蛋白质 2.5 g/kg、脂肪 1 g/kg、糖上限 0.5 g/kg，全部可改
- 数据存在浏览器本地，关掉再开还在
- 截图：界面纯文字、没有多余按钮，直接手机截屏即可

## 统计怎么算

统计页的三段是**滚动窗口**，不是日历周期：

- 近 7 天 = 今天往前数 7 天（含今天）
- 近 30 天、近 365 天同理

每段显示「N 天中 M 天有记录」，均值**只按有记录的天数算**——今天开始用，不会因为前面没记而被平均成很低的值。

卡片下面「有记录的日子」按时间倒序，点任意一天直接跳回那天的记录。

## 热量是怎么来的

**没有录入热量，热量是算出来的。**

你给的只有蛋白质、碳水、脂肪、糖的克数，界面上的 kcal 全部按营养学通用系数换算：

```
热量 = 蛋白质 × 4 + 碳水 × 4 + 脂肪 × 9
```

糖不参与计算——糖是碳水的一部分，已经算在碳水里了，单独统计只是为了让添加糖可见。

几个例子：

| 食物 | 蛋白 · 碳水 · 脂肪 | 热量 |
| --- | --- | --- |
| 鸡蛋 | 6 · 0 · 5 | 69 |
| 玉米 | 3 · 30 · 2 | 150 |
| 牛肉 300g | 60 · 4 · 15 | 391 |
| 米粉 200g | 10 · 140 · 2 | 618 |

系数来自 Atwater：蛋白和碳水各约 4 kcal/g，脂肪约 9 kcal/g。这是通行的估算值，和包装上标的热量会有一点点出入（膳食纤维、酒精、有机酸都不在模型里）。

要精确到包装标注值，就在食物里直接填热量（见下）。

## 数据

存在浏览器的 localStorage，键名 `foodrecord.v1`。

换手机、清理浏览器数据会丢，所以「设置」页里有导出备份（JSON）和导入备份。**换设备前先导出。**

## 直接填热量（覆盖公式）

包装食品的营养成分表上都有现成的热量，照抄最准。

食物库 → 新建 / 编辑食物 → 最后一行「热量（可选）」填上数字。填了就一律用这个值，留空才走公式。

- 填了热量的食物，记录时数量面板会标注「直接填的」
- 汇总、进度条、每日总量都会用这个值
- 清空这一格就退回公式换算

已有记录存的是当时的快照，改食物不会改历史。

## 改食物数据

- 单个改：食物库 → 点某个食物 → 改数值 → 完成
- 批量改：编辑 `index.html` 里 `DEFAULT_FOODS` 那段，然后「设置」页点「清空所有记录」会重新载入默认食物

注意：修改食物库里的数值，不会影响已经记录过的条目（历史记录存的是当时的快照）。
